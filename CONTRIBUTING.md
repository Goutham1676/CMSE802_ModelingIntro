# Contributing to this Repository

One goal of this course is to help students develop professional software development habits.

A simple way to contribute is by submitting GitHub Issues.

## When Should I Open an Issue?

Consider opening an issue if you find:

- incorrect code
- broken instructions
- missing files
- confusing explanations
- typos
- unexpected behavior
- suggestions for improvement

You do not need to know how to fix the problem.

Simply describing the issue clearly is often enough.

## How to Open an Issue

1. Navigate to the repository on GitHub.
2. Select the "Issues" tab.
3. Click "New Issue".
4. Provide a short, descriptive title.
5. Describe:
   - what happened,
   - what you expected,
   - any relevant screenshots or error messages.
6. Submit the issue.

## Example Issue Titles

Good:

- Typo in Exercise 3 instructions
- Notebook 2 import statement fails on Windows
- Triangle label overlaps figure edge

Less Helpful:

- Broken
- Doesn't work
- Help

## Advanced Contributions

Experienced Git users are welcome to submit pull requests.

However, opening a clear issue is often the best first step and is encouraged for everyone.
